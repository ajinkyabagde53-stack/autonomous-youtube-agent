# Research Inputs

Optional local research notes. They are only used when you pass
`--local-research research` to `main.py`; reference-channel runs leave them
out by default so notes about your own niche can't skew a run.

Recommended folders:

- `youtube/`
- `reddit/`
- `search/`
- `transcripts/`

Supported formats are Markdown and plain text. Each file becomes one research
item titled by its first line. README files are ignored.
